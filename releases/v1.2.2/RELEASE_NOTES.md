## 📱 Instalación

### Para Google Play Store
1. Sube el archivo `Pathly-v1.2.2-release.aab` a Google Play Console
2. El AAB será procesado automáticamente para generar APKs optimizados por dispositivo

### Para Distribución Directa
1. Usa el archivo `Pathly-v1.2.2-release.apk` para distribución directa
2. Habilita "Instalar aplicaciones de fuentes desconocidas" en tu dispositivo Android
3. Instala el APK
4. ¡Disfruta jugando Pathly con el sistema de vidas corregido!
